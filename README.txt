# Anas & Rabiya — Luxury Valima Invitation

## Replace these files in the root of your GitHub repository
- `index.html`
- `style.css`
- `script.js`

Keep your existing `assets/` folder. In particular, keep `assets/music.mp3` if you want the sound toggle to work.

## Publish
1. Open the `Anas-rabiya-wedding` repository on GitHub.
2. Replace the three files above with the files from this package.
3. Commit the changes to the `main` branch.
4. Wait for GitHub Pages to publish, then open the site in a private/incognito tab or refresh after clearing the browser cache.

## Included interactions
- CSS-built velvet gift box with wide ribbon, layered bow loops and tails.
- Ribbon release and two-door opening animation.
- Red velvet curtain reveal (the content is present before the curtain opens, avoiding a black transition screen).
- Tap-to-open letter.
- Press-and-hold wax seal to reveal date and calendar link.
- Countdown, venue directions, optional music and share action.
