# Anas & Rabiya — Valima Invitation

A responsive, single-page digital Valima invitation designed with a deep emerald and antique-gold palette.

## Files
- `index.html` — invitation structure and event details
- `style.css` — responsive styling, 3D envelope and reveal animations
- `script.js` — opening sequence, scroll reveals, countdown, music and share actions
- `feather-envelope.png.webp` and `save-date-feather.png` — original supplied artwork (kept in the project)
- `assets/music.mp3` — supplied background music

## Run locally
Open `index.html` in a browser. Internet access is required for the Google Fonts stylesheet; the page otherwise uses local assets.

## Publish on GitHub Pages
Upload the contents of this folder to the root of your GitHub Pages repository and commit the changes. Keep the `assets` folder and all filenames unchanged.
