# Anas & Rabiya — Valima Invitation

A mobile-first, single-page digital Valima invitation with a burgundy velvet / antique gold visual direction inspired by the cinematic pacing of the supplied reference.

## Deploy to GitHub Pages

1. Extract this ZIP.
2. Upload the contents of this folder to the repository root (not the enclosing folder).
3. Keep `assets/music.mp3` at exactly that path.
4. Commit the changes. GitHub Pages should publish from the configured `main` branch/root.

## Included interactions

- CSS-built gift box opening sequence and curtain reveal
- Interactive invitation letter
- Press-and-hold wax seal date reveal
- Local `.ics` calendar download
- Event countdown using Karachi time (UTC+5)
- Google Maps directions and embedded location map
- Optional background music, share and RSVP message actions
- Reduced-motion support and responsive mobile layouts
