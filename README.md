# Anas & Rabiya — Walima Invitation

A responsive, cinematic digital Walima invitation website.

## Included
- Animated opening screen
- Anas & Rabiya invitation page
- Walima details: 17 January 2027, 8:00 PM
- The Liberty Ballroom, Karachi
- Live countdown
- Google Maps directions
- Share invitation button
- Optional background music control
- No RSVP or attendance tracking

## Add your music
Place a licensed/royalty-free romantic instrumental MP3 in `assets/` and name it `music.mp3`.
The music button is included. Browsers require guests to tap the music button before playback.

## Publish with GitHub Pages
1. Open your existing repository `Anas-rabiya-wedding`.
2. Choose **Add file → Upload files**.
3. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder.
4. Commit the changes to the `main` branch.
5. Open **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select branch `main` and folder `/ (root)`, then Save.
8. Wait a minute or two; GitHub Pages will show your live website URL in Settings → Pages.

You can test locally by opening `index.html` in a browser. Google Fonts require an internet connection.
